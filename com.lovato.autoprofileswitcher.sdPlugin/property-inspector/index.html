Auto Profile Switcher

Maps any Windows processes to StreamDeck profile names.

  • Process name works by partial match (e.g. "teams" matches "ms-teams.exe").
  • Optionally add a window title match for finer control (e.g. "PowerShell" matches "Windows PowerShell").
  • Finally, select the profile to switch to when a match is found.
