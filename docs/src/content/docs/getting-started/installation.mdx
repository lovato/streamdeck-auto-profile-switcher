## Elgato Marketplace (recommended)

Download from the [Elgato Marketplace](https://marketplace.elgato.com/product/auto-profile-switcher-7fb50ad5-66e7-4a0e-9567-46169823fcd3) and install like any other plugin.

## Manual install

1. Download the latest `.streamDeckPlugin` from [GitHub Releases](https://github.com/lovato/streamdeck-auto-profile-switcher/releases).
2. Double-click the file — Stream Deck installs it automatically.

## After install

1. Open Stream Deck.
2. Find **Auto Profile Switcher** under actions.
3. Drag it onto **any** profile key — it only needs to exist once on your deck.

The action is a monitor, not a button you press during normal use. A settings or utility profile is a good place for it.
